
﻿# SmartStall Operator

A mobile application used to control and monitor a semi-automatic robotic toilet cleaning system.

## Features (Planned)
- ESP32 communication (Bluetooth/WiFi)
- OpenCV / AI integration
- Firebase integration

## Architecture
- **Framework:** Flutter (Material 3)
- **State Management:** Riverpod
- **Routing:** GoRouter
- **Pattern:** Feature-first Clean Architecture
- **Design:** Soft Glassmorphism (Inter typography, #E0F2FE to #FCE7F3 gradient)
